# pincer_shared

Shared runtime helpers (`Pincer.Channels.Shared.TokenCache` and `Pincer.Channels.Shared.WebhookVerifier`) for channel adapters in the [Pincer](https://github.com/manelsen/Pincer) AI agent framework.

## Installation

```elixir
def deps do
  [
    {:pincer_shared, "~> 0.1"}
  ]
end
```
